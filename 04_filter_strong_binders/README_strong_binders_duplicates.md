# Why are there duplicate rows in strong_binders_peptide_wt_metrics.csv?

## Cause

**One peptide can be a strong binder for more than one HLA allele.**

The pipeline does the following:

1. **NetMHCpan** is run for each of the 1,739 unique 9-mers against **9 HLA alleles** (e.g. HLA-A01:01, HLA-A02:01, …, HLA-C07:02).
2. **Strong binders** are defined as (peptide, allele) pairs with **EL_Rank ≤ 0.5**.
3. The strong-binder table therefore has **one row per (peptide, allele)** that passes the threshold — so the same peptide can appear multiple times if it is predicted to bind strongly to several alleles.
4. **nsclc_netmhcpan_strong_binders.csv** keeps that structure (it has an `allele` column).
5. **strong_binders_peptide_wt.csv** (and then **strong_binders_peptide_wt_metrics.csv**) were built by taking only the peptide and wildtype (and distance metrics) from that table, **without** the allele. So every (peptide, allele) row became a row with the same (peptide, wt) — hence **duplicate (peptide, wt) rows** whenever a peptide is strong for more than one allele.

## Numbers (this run)

- **Total rows** in `strong_binders_peptide_wt_metrics.csv`: 444 (one per strong peptide–allele pair).
- **Unique (peptide, wt) pairs**: 167.
- So many rows are duplicates in terms of peptide and wt; they differ only by which HLA allele the prediction was for (information that was dropped when creating the peptide–wt-only files).

## If you need one row per peptide

- Use **nsclc_netmhcpan_strong_binders.csv** if you need allele information (one row per peptide–allele).
- To get **one row per unique peptide** (no allele duplicates), deduplicate on `peptide` (or on `peptide` and `wt_peptide`), e.g. keep the first row per peptide or aggregate (e.g. list alleles).  
  Example: `strong_binders_peptide_wt_metrics_unique.csv` can be generated by dropping duplicates on `peptide` (see script or one-liner below).

Example (Python) to create a unique-peptide metrics file:

```python
import pandas as pd
df = pd.read_csv("strong_binders_peptide_wt_metrics.csv")
df_unique = df.drop_duplicates(subset=["peptide"], keep="first")
df_unique.to_csv("strong_binders_peptide_wt_metrics_unique.csv", index=False)
```
